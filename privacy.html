Privacy policy

This policy covers the privately operated ViceByte YouTube Automation desktop tool and this informational website.

Google and YouTube data we access

When the operator grants access through Google OAuth, the desktop tool uses the YouTube Data API to verify the authorized channel ID and channel name. It can read upload listings, video IDs, titles, descriptions, tags, thumbnails, visibility, processing and available restriction information, audience settings, and scheduled release times. With the appropriate granted permissions, it sends the selected video, thumbnail, metadata, and scheduling information to YouTube to manage the operator’s own channel.

Google handles sign-in and consent. The desktop tool does not ask for or store a Google password. This website provides information about the tool and does not initiate Google sign-in or collect OAuth credentials.

How we use and share data

We use Google and YouTube data to verify which channel the operator authorized, prevent duplicate uploads, perform authorized channel actions, and confirm their results. We do not sell this data or use it for advertising or unrelated profiling. The desktop tool sends information to Google and YouTube as needed to authorize access and carry out channel operations. Video and related information may become visible to viewers when the operator publishes it through YouTube.

Local storage, token renewal, and retention

Access tokens are held in memory during a session. When offline access is authorized and a refresh token is returned, the desktop tool can store that refresh token in Windows Credential Manager under the operator’s Windows account. The saved token is tied to the OAuth client, channel, and permission scope and is used to request replacement access tokens from Google. OAuth client configuration and tokens stay outside the public site files.

The refresh token is kept while the operator needs access and can be removed from Windows Credential Manager. Local project and operation records may retain video IDs, metadata, and action results for channel management, auditing, and duplicate prevention. The operator reviews those records and deletes data when it is no longer needed, subject to applicable YouTube API requirements.

Revoke access or request deletion

Revoke the tool’s access from Google Account connections. To remove the local copy, delete the saved ViceByte YouTube credential in Windows Credential Manager. To request deletion of related local records or ask about retention, email vicebytegaming@gmail.com. Content stored on YouTube can be managed separately in YouTube Studio.

Google API policies

ViceByte YouTube Automation’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements where applicable. The tool uses YouTube API Services. See the YouTube Terms of Service and Google Privacy Policy.

Website hosting and contact

This informational site does not use analytics scripts, advertising cookies, or contact forms. GitHub Pages may process ordinary request information as the hosting provider. See the GitHub Privacy Statement.

For privacy questions or requests, contact vicebytegaming@gmail.com.
